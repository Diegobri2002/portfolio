Website Redesign & Restructure

Proyecto enfocado en la optimización de experiencia mediante rediseño estructural y mejora de arquitectura de información.

Más que una actualización visual, este proyecto se centró en reorganizar contenido, mejorar navegación y alinear la experiencia del sitio con objetivos de negocio y claridad comunicativa.

Rol:
UX / UI Designer · Webflow Designer
Enfoque:
UX Optimization · Information Architecture
Año:
2022

Contexto

El sitio original presentaba problemas de estructura, jerarquía visual y claridad de contenido, afectando la experiencia del usuario y la efectividad de la comunicación.

Aunque contenía información relevante, esta no estaba organizada estratégicamente, generando fricción en la navegación.

El objetivo fue transformar el sitio en una experiencia clara, intuitiva y alineada con objetivos de negocio.

El Problema

  • ✔ Navegación poco clara
  • ✔ Jerarquía visual inconsistente
  • ✔ Contenido desorganizado
  • ✔ Estructura de páginas poco lógica
  • ✔ Baja claridad en mensajes clave

Estos factores impactaban directamente en la usabilidad y percepción del sitio.

Proceso

Auditoría UX

Se analizó el sitio existente para detectar puntos de fricción, inconsistencias visuales y problemas estructurales.

Arquitectura de Información

Se reorganizó completamente el contenido, agrupando información de forma lógica y simplificando la navegación para reducir carga cognitiva.

Rediseño UI

Se desarrolló una nueva interfaz con jerarquía tipográfica clara, mejor espaciado y componentes consistentes para facilitar el escaneo visual.

Prototipado

Se generaron prototipos para validar flujos de navegación y distribución de contenido antes de implementación.

Resultado

  • ✔ Navegación más intuitiva
  • ✔ Mejor organización del contenido
  • ✔ Mayor claridad en comunicación
  • ✔ Experiencia más fluida
  • ✔ Base sólida para escalabilidad

El sitio evolucionó de una estructura confusa a una experiencia clara y orientada al usuario.

Conclusión

Este proyecto demuestra que un rediseño efectivo va más allá de lo visual: requiere una correcta estructuración de la información y entendimiento profundo del usuario.

La optimización de UX permitió transformar la efectividad del sitio como herramienta de comunicación y negocio.

Un caso claro de cómo el UX impacta directamente en la calidad de un producto digital.
