Case Study

HealthPod — Rediseño y construcción del sitio web corporativo

Traducción estratégica de un sistema de salud complejo en una experiencia digital clara, moderna y orientada a conversión.

Rol
Product Designer
Enfoque
UX Strategy · UI System · Front-End
Stack
HTML · CSS · Tailwind · JS · GitHub

Contexto

El sitio web debía comunicar con claridad qué es HealthPod, cómo funciona y cuáles son sus beneficios para residenciales, corporativos y usuarios finales.

Además, debía funcionar como herramienta comercial para generar confianza en inversionistas y potenciales clientes.

Reto

Traducir un sistema tecnológico complejo en una narrativa clara, comprensible y atractiva para distintos públicos.

El sitio debía equilibrar comunicación institucional, claridad operativa y orientación comercial.

Arquitectura de Información

Se diseñó una estructura clara basada en bloques modulares que permitieran explicar el producto de forma progresiva.

  • Propuesta de valor
  • Cómo funciona
  • Beneficios por segmento
  • Proceso de implementación
  • Llamados a la acción estratégicos

Sistema Visual

El diseño mantiene coherencia con el producto digital, utilizando jerarquías claras, uso estratégico del color y bloques visuales amplios que facilitan la lectura.

Se priorizó claridad, confianza y estructura modular.

Resultados

El sitio logró comunicar con claridad la propuesta de valor del ecosistema HealthPod, fortalecer su posicionamiento institucional y funcionar como herramienta comercial estratégica.

Conclusión

El desarrollo del sitio web de HealthPod permitió consolidar la narrativa del producto en un entorno digital claro, estructurado y orientado a negocio.

El proyecto reforzó la importancia de la arquitectura de información, la claridad jerárquica y la alineación estratégica entre diseño, comunicación y objetivos comerciales.
